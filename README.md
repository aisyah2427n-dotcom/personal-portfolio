# Personal Portfolio - Syaira Novka Syaidina 🚀

Website portofolio pribadi satu halaman yang dirancang dengan gaya **Glassmorphism**, bernuansa warna *light pastel blue*, serta responsif untuk perangkat seluler maupun desktop.

---

## 🛠️ Teknologi yang Digunakan
* **HTML5** – Struktur halaman web semantik.
* **CSS3** – Desain kustom, efek visual, dan layout responsif (tanpa framework tambahan).
* **JavaScript (Vanilla)** – Animasi kemunculan elemen saat di-scroll (*Intersection Observer*).
* **Formspree** – Layanan penampung formulir pesan secara langsung ke email.
* **Font Awesome & Google Fonts** – Ikon modern dan tipografi *Plus Jakarta Sans*.
